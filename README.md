## 모션 & Manim 영상

슬라이드 진입 연출은 `assets/deck-motion.js`(anime.js v3)가 담당합니다. `runtime.js`는 건드리지 않고 `body[data-current-slide]` 변화를 감지해 동작하며, 색은 CSS 변수에서 읽어 테마 전환을 따라갑니다.

| 구조 | 연출 |
|---|---|
| 표지 `.cover` | eyebrow → 제목 단어 stagger → 리드 → 메타 4칸 · 마크 SVG 선 그리기 |
| 파트 표지 `.hero` | 대형 숫자 → 괘선 → 필 → 제목 단어 stagger → 부제 · 시각표 |
| 본문 | 키커 → 제목 단어 stagger → 항목(카드 · 표 행 · 목록) stagger → 하단 라벨 → 강조 카드 |
| `.versus` | 왼쪽 → **vs** 배지 팝 → 오른쪽 |
| `[data-flow]` | 카드 위 타임라인(선 · 점 · 화살표) |
| `[data-formula]` | 카드 사이 **+** → **=** 결과 문장 |
| `video` | 진입 시 자동 재생 · 이탈 시 정지 · 클릭 또는 `↻ 다시 재생` |

- `R` 키: 현재 슬라이드 연출 다시 재생 · 발표자 미리보기(`?preview=N`)와 `prefers-reduced-motion`에서는 연출 생략

### Manim 영상 (에디토리얼 페이퍼 팔레트)

| 파일 | 삽입 슬라이드 | 내용 |
|---|---|---|
| `assets/manim_mece.mp4` (20s) | 18 · 3-1 MECE | 기획서 하나를 나누면 — '경쟁 사례'의 중복, '리스크'의 누락을 고쳐 5항목으로 |
| `assets/manim_red_team.mp4` (19s) | 24 · 4-2 Red Teaming | 반대편에서 읽으면 — 심사위원·경쟁사·회계의 반박 → 보완(사람) → 재검토 → 통과 |

소스는 `manim/`, 색은 `manim/palette.py`에서 관리합니다. 재렌더:

```bash
# 저장소 루트에서 (Manim 0.20+, 시스템 폰트 Noto Sans KR · Noto Serif KR 필요)
PYTHONPATH=manim manim -qh manim/mece.py Mece
PYTHONPATH=manim manim -qh manim/red_team.py RedTeam
cp media/videos/mece/1080p60/Mece.mp4 assets/manim_mece.mp4
cp media/videos/red_team/1080p60/RedTeam.mp4 assets/manim_red_team.mp4
```

## 슬라이드 조작 단축키

| 키 | 기능 |
|---|---|
| `←` `→` / `Space` | 이동 |
| `S` | 발표자 모드 (별도 창 · 현재/다음 미리보기 · 대본 · 타이머) |
| `O` | 전체보기 그리드 |
| `N` | 스피커 노트 토글 |
| `T` | 테마 전환 · paper(기본) ↔ ink(다크) |
| `F` | 전체화면 |
| `R` | 연출 다시 재생 (발표자 창에서는 타이머 리셋) |
